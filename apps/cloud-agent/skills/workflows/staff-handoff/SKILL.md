# 업무 인계

이 스레드의 대화에서 다음 직원에게 필요한 작업 정보를 추출한다. 전체 이력이 필요하면 get_source_thread_history로 읽고 complete와 nextCursor를 확인한다. 읽은 범위가 불완전하면 요약에 범위를 표시한다.

1. 결정 사항과 실제 완료 증거를 찾아 완료된 일을 적는다. 계획·요청·예정은 완료로 바꾸지 않는다.
2. 남은 작업마다 담당, 기한, 선행 조건, 완료 확인 방법을 적는다. 메시지에 없는 담당이나 기한은 임의 지정하지 않는다.
3. 서로 모순되는 날짜나 지시, 답을 기다리는 질문을 별도 표시한다. 가장 먼저 해결해야 할 질문 하나를 제시한다.
4. 요청한 문서 형태로 간단한 체크리스트·인계 요약·회의 메모를 만든다. 원문의 개인 연락처·환자 정보·비밀번호는 인계 문서에 불필요하게 복사하지 않는다.

외부 저장·발송 도구가 없으면 이 스레드에 초안만 작성한다. 다른 직원 초대나 다른 방 이동을 제안된 인계의 일부로 자동 실행하지 않는다.
